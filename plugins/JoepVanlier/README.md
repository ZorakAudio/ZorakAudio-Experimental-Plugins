# JoepValier upstream JSFX bundle

50 JSFX entry points converted to the repository plugin leaf format.

Extract this tree at the repository root; it creates `plugins/JoepValier/<PluginKey>/...`.

The source author is **Joep Vanlier**; the category folder name `JoepValier` follows the requested repository path spelling.
